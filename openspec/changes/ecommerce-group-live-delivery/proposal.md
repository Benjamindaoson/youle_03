## Why

The existing ecommerce detail-image Skill is a mock-validated workflow that can create an uncontrolled batch of images. The product needs a real, low-cost Chinese-model delivery path that remains entirely inside a professional group chat.

## What Changes

- Define an ecommerce professional group with only the roles needed for image-and-copy delivery.
- Require an explicit user confirmation for the quantity of every image-model invocation.
- Make Chinese providers the default path and prohibit implicit overseas fallback or retry spending.
- Remove duplicate or stub-only ecommerce paths that bypass this group contract.

## Capabilities

### New Capabilities

- `ecommerce-group-live-delivery`: Real ecommerce copy and detail-image delivery inside a confirmation-gated professional group chat.

### Modified Capabilities

- None.

## Impact

Existing ecommerce Skill YAML, group membership, confirmation/HITL persistence, model routing, image handlers, frontend group-event UI, tests, and production configuration.
